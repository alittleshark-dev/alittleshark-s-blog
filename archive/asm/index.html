第一个汇编的Hello World!


接下来环境都配置好后就可以开始写代码啦
这是一个Hello World的简单示例 
; ./code/hello.asm
; 数据
section .data
    msg db "Hello World", 0xA ; 0xA换行符
    len equ $ - msg

section .text
    global _start

_start:
    ; sys_write
    mov rax, 1        ; 系统调用号 1 = sys_write
    mov rdi, 1        ; 文件描述符 1 = stdout
    mov rsi, msg      ; 字符串地址
    mov rdx, len      ; 字符串长度
    syscall

    ; sys_exit
    mov rax, 60       ; 系统调用号 60 = sys_exit
    xor rdi, rdi      ; 退出码 0
    syscall

运行


第一步：汇编 / Assemble

把 .asm 源代码转换成机器码目标文件（.o）：

nasm -f elf64 hello.asm -o hello.o

参数说明：

-f elf64：指定输出格式为 64 位 ELF（Linux 的可执行文件格式) -o hello.o：输出文件名

第二步：链接 / Link

将目标文件链接成可执行程序：

ld hello.o -o hello

说明：ld 是 GNU 链接器，它会把你的代码和操作系统规范结合起来，生成最终的可执行文件 hello。


第三步：运行 / Run!

直接执行生成的可执行文件：

./hello

预期输出：

[user@WSL ~/asm]$ ./hello
Hello World
[user@WSL ~/asm]$
